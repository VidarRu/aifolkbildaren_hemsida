# aifolkbildaren.se

Hemsidan för AI-Folkbildaren – Vidar Kjerstadius AI-utbildningar för bibliotek.

Byggd med vanlig HTML och CSS och publicerad med GitHub Pages. Se [`PROGRESS.md`](PROGRESS.md) för planen för flytten från WordPress.

## Förhandsgranska lokalt

```bash
python3 -m http.server 8000
```

Öppna sedan http://localhost:8000.
